Gambar Program JLPT

Level Dasar

Persiapan JLPT N5-N4

Program intensif untuk membangun dasar bahasa Jepang dan menyiapkan peserta menghadapi ujian JLPT resmi level N5 sampai N4.

Durasi
6-12 bulan
Cocok Untuk
Pemula dan calon peserta JLPT
Target
Kesiapan N5-N4

Materi Utama

  • Hiragana, katakana, dan kanji dasar
  • Grammar, kosakata, dan pola kalimat N5-N4
  • Latihan membaca, listening, dan mock test JLPT

Hasil Akhir

  • Memahami percakapan dasar sehari-hari
  • Siap mengikuti simulasi dan ujian JLPT
  • Mendapat evaluasi progres belajar berkala

Gambar Program SSW

Kerja Terampil

Program Tokutei Ginou (SSW)

Program untuk peserta yang ingin mengejar peluang kerja terampil di Jepang melalui jalur Specified Skilled Worker atau Tokutei Ginou.

Durasi
3-6 bulan
Cocok Untuk
Calon pekerja terampil
Target
Bahasa dan kesiapan kerja

Materi Utama

  • Bahasa Jepang untuk lingkungan kerja
  • Kosakata bidang industri dan pelayanan
  • Persiapan wawancara, dokumen, dan budaya kerja

Hasil Akhir

  • Lebih siap mengikuti proses seleksi kerja
  • Memahami etika kerja dan komunikasi profesional
  • Mendapat arahan jalur kerja sesuai kemampuan

Gambar Program Magang

Persiapan Magang

Kelas Intensif Persiapan Magang

Program persiapan menyeluruh untuk calon peserta magang ke Jepang, dengan fokus pada bahasa praktis, kedisiplinan, mental kerja, dan adaptasi budaya.

Durasi
2-4 bulan
Cocok Untuk
Calon peserta magang
Target
Siap seleksi dan keberangkatan

Materi Utama

  • Percakapan harian dan instruksi kerja dasar
  • Etika, disiplin, dan kebiasaan kerja di Jepang
  • Latihan wawancara, orientasi, dan pembekalan keberangkatan

Hasil Akhir

  • Lebih percaya diri saat seleksi dan wawancara
  • Memahami dasar komunikasi di tempat kerja
  • Siap mengikuti arahan penyaluran dan pembekalan

Alur Mengikuti Program

Peserta akan diarahkan dari konsultasi awal sampai evaluasi, sehingga program yang dipilih sesuai dengan tujuan dan kemampuan awal.

1

Konsultasi Program

Tim Kayuki membantu memilih jalur belajar sesuai target peserta.

2

Penempatan Level

Peserta mengikuti pengecekan kemampuan awal sebelum kelas berjalan.

3

Pembelajaran Intensif

Materi diberikan bertahap dengan latihan bahasa, tugas, dan evaluasi.

4

Evaluasi dan Arahan

Peserta mendapat arahan lanjutan untuk ujian, seleksi, atau keberangkatan.
